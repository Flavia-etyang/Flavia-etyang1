# Evidence vs. Inference

## Framework

| Stage | Question |
|---|---|
| **Observation** | What is directly visible? |
| **Inference** | What does it suggest? |
| **Validation** | What independent evidence supports it? |
| **Assessment** | What conclusion is justified? |
| **Confidence** | How strong is the evidence? |

Each stage is kept explicitly separate. A hypothesis is never presented
as an observed fact.

## Worked example

**Observation**
Longitudinal pipes are visible on deck.

**Inference**
Liquid-cargo transfer infrastructure may be present.

**Classification (hypothesis)**
Tanker hypothesis.

**Validation**
Compare against vessel particulars, AIS history, and external vessel
databases where available.

**Assessment**
Classification confidence increases if validation is consistent with the
tanker hypothesis; it does not increase — and may decrease — if
independent sources conflict with it.

## Why this separation matters

Overhead imagery provides *evidence*, not certainty. Skipping straight
from observation to conclusion (e.g. "pipes visible → this is a crude
oil tanker") discards the analytical steps that let a reader judge how
much weight the conclusion deserves. Every case study in this repository
follows this structure so that observation, inference, and conclusion
remain distinguishable from one another.
