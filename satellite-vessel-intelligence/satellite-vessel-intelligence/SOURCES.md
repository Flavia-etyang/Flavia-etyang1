# Sources & Data Governance

## Governing principle

Only public or appropriately licensed imagery is used in this portfolio.
This repository does **not** include:

- Proprietary satellite imagery
- Confidential employer screenshots
- Client information
- Internal datasets
- Restricted workflows or proprietary methodologies belonging to any
  current or former employer

All vessel imagery in this repository is represented by **original,
clearly labelled SVG illustrations** — never by imagery that could be
mistaken for actual satellite or aerial data. All vessel identifiers in
`data/vessel-assessments.csv` and the case studies are illustrative
placeholders (`EXAMPLE-V01`, etc.), not real vessel identities.

## Source record template

For any real case added to this repository in the future, the following
should be recorded for each image or dataset used:

| Field | Description |
|---|---|
| Provider | Imagery or data provider (e.g. satellite operator, open data platform) |
| Sensor | Sensor type (EO, SAR, etc.) and, where known, resolution |
| Acquisition date | Date the source imagery was captured |
| Geographic area | General area covered, at a level appropriate for public disclosure |
| License / attribution | License terms and required attribution |
| Supporting vessel-data sources | Any AIS, registry, or particulars sources used for validation |
| Access date | Date the source was accessed |

## Current status

No real satellite imagery, AIS records, or vessel-particulars data are
included in this version of the repository. All content is illustrative.
